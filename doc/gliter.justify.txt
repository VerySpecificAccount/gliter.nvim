1. gliter.justify                              *gliter.justify-gliter.justify*

Flush both margins: `g=` reflows the paragraph around the cursor to the width
and distributes the leftover spaces between the words, so the right edge comes
out straight — every line but the last, the way a justified paragraph in a
book does. On a Visual selection (or a `:GliterJustify` range) it justifies
exactly those lines.

>lua
    require('gliter').setup { justify = {} }
    -- or on its own:
    require('gliter.justify').setup {}
<


WHAT IT DOES                      *gliter.justify-gliter.justify-what-it-does*

Two things happen, in this order:

1. **the reflow** — the paragraph’s words are re-wrapped to the width,
greedy, exactly like `gq`’s filling. Short, ragged input lines become
full ones.
2. **the justification** — every line but the last of the paragraph gets
its slack distributed between the words: `the  quick  brown  fox`, the
leftmost gaps taking the odd space. The last line stays ragged (that is
what the last line of a justified paragraph looks like); a line with a
single word cannot be stretched and stays as it is; a word wider than
the width is left alone rather than broken.

A common leading indent is kept on every line and paid for out of the width;
tabs are expanded first. The cursor stays on its line.


KEYS AND COMMANDS            *gliter.justify-gliter.justify-keys-and-commands*

  -------------------------------------------------------------------------
  Key / command                                  Action
  ---------------------------------------------- --------------------------
  g=                                             justify the paragraph
                                                 around the cursor (n); the
                                                 selection (x)

  [count]g=                                      the same, to [count] as
                                                 the width

  :GliterJustify [width]                         justify a range
                                                 (:5,20GliterJustify 60);
                                                 no range — the paragraph;
                                                 no width — textwidth, or
                                                 80 when it is zero
  -------------------------------------------------------------------------
`gq` (`gqq`, `gqip`, …) keeps doing what it always did — fill without
justifying. This is the button next to it for when you want the right edge
straight.


OPTIONS                                *gliter.justify-gliter.justify-options*

>lua
    require('gliter.justify').setup {
      keys = {
        justify = 'g=',     -- set to false to unmap; the command stays
      },
      width = nil,          -- nil: 'textwidth' when nonzero, else 80;
                            -- a count or the :GliterJustify argument wins
    }
<


STOLEN FROM                        *gliter.justify-gliter.justify-stolen-from*

Two halves of an old idea. Emacs’ `M-q` (fill.el, 1980s) has reflowed
paragraphs since before Vim existed, and `set-justification-full` is the
flush-both-margins mode gliter.justify reproduces. Neovim ships the other half
— the `justify` dist plugin (Preben "Peppe" Guldberg, 1998) — which pads
lines in place but never moves a word between them, so a ragged paragraph stays
ragged. gliter.justify is the two together: the reflow of `M-q`, the space
distribution of justify.vim, in Lua, with the cursor kept.

Requires Neovim 0.9+.
