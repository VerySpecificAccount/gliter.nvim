# gliter documentation

One page per module. Every module is opt-in; see the
[main README](../README.md) for setup and defaults.

## Modules

- [`gliter.netrw`](gliter.netrw.md) — marks, bookmarks, editable listing for netrw
- [`gliter.undotree`](gliter.undotree.md) — the branching undo tree, colored
- [`gliter.multicursor`](gliter.multicursor.md) — keys for the built-in multicursors
- [`gliter.treesitterRE`](gliter.treesitterRE.md) — expand-region ladder
- [`gliter.ctags`](gliter.ctags.md) — tags with quickfix
- [`gliter.make`](gliter.make.md) — the `*compilation*` buffer
- [`gliter.repl`](gliter.repl.md) — REPL per filetype
- [`gliter.textobj`](gliter.textobj.md) — targets.vim quote/separator objects
- [`gliter.sessions`](gliter.sessions.md) — `:mksession` with a memory
- [`gliter.readme`](gliter.readme.md) — recentf for readmes
- [`gliter.justify`](gliter.justify.md) — reflow + justify
- [`gliter.matchit`](gliter.matchit.md) — keyword `%`
- [`gliter.tohtml`](gliter.tohtml.md) — export as HTML/Markdown/PDF
- [`gliter.w3`](gliter.w3.md) — the web in a buffer
- [`gliter.cmd`](gliter.cmd.md) — readline keys + fish ghost
- [`gliter.which`](gliter.which.md) — light which-key
- [`gliter.screenkey`](gliter.screenkey.md) — show your keys
